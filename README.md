## 🛠️ **Tecnologias Utilizadas**

Aqui estão as tecnologias utilizadas no projeto, com uma breve explicação e links para suas documentações oficiais.

### **1. Astro**  
- **O que é?** Um moderno framework focado em gerar sites estáticos rápidos e eficientes. Ele permite o uso de componentes de várias bibliotecas (React, Vue, Svelte) de forma integrada.  
- **Funcionalidade Principal:** Renderização otimizada, componentes leves e suporte a diversas bibliotecas.  
- 📖 [Documentação Oficial do Astro](https://docs.astro.build/)

---

### **2. Bootstrap**  
- **O que é?** Um framework CSS popular para criar interfaces responsivas e modernas com rapidez.  
- **Funcionalidade Principal:** Sistema de grid, componentes prontos (botões, modais, cards) e suporte para temas escuros/claro.  
- 📖 [Documentação Oficial do Bootstrap](https://getbootstrap.com/)

---

### **3. JavaScript (Vanilla)**  
- **O que é?** Linguagem de programação utilizada para adicionar interatividade ao site.  
- **Funcionalidade Principal:** Manipulação do DOM, controle de eventos e armazenamento de preferências no `localStorage`.  
- 📖 [Documentação MDN JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)

---

### **4. TypeScript**  
- **O que é?** Um superset do JavaScript que adiciona tipagem estática, ajudando a evitar erros no código.  
- **Funcionalidade Principal:** Segurança no desenvolvimento e melhores ferramentas de depuração.  
- 📖 [Documentação Oficial do TypeScript](https://www.typescriptlang.org/)

## ⚙️ **Como Rodar o Projeto**

### **Pré-requisitos**
- [Node.js](https://nodejs.org/)
- [Yarn](https://yarnpkg.com/)

### **Passo a Passo**

1. **Clone o Repositório:**
   ```bash
   git clone https://github.com/lucascorreaa/astro-bootstrap-landing.git
   cd astro-bootstrap-landing
   ```

2. **Instale as Dependências:**
   ```bash
   yarn
   ```

3. **Inicie o Servidor de Desenvolvimento:**
   ```bash
   yarn dev
   ```

4. **Acesse o Projeto no Navegador:**  
   - [http://localhost:4321](http://localhost:4321)
